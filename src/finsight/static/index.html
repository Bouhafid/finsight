FinSight

Ask questions about Apple's 10-K filings. Every figure comes from SEC XBRL data, and every sentence is backed by a verbatim quote.

How it works

  1. Figures: revenue, income and assets come from Apple's XBRL filings; margins and growth are computed in Python. No language model writes a number.
  2. Retrieval: the question is embedded and matched against 10-K passages in Postgres with pgvector.
  3. Generation: the model writes short claims that must cite the retrieved passages. Claims with figures are discarded.
  4. Verification: each claim is split into atomic statements. A claim is kept only when every statement is supported by a quote found word for word in the cited passage.
Data: SEC EDGAR, Apple 10-K filings FY2023 to FY2025. Not investment advice. · API documentation
